# Relógio Digital em C

Projeto desenvolvido em C que simula um relógio digital no terminal, utilizando a hora informada pelo usuário como ponto inicial.

## Funcionalidades

- Entrada de horário no formato HH:MM:SS
- Validação do horário informado
- Exibição do horário no terminal
- Atualização automática dos segundos
- Controle de minutos, horas e mudança de dia
- Utilização de `struct` para representar o horário

## Como executar

Compile o arquivo `relogio_digital.c` utilizando um compilador C.

Exemplo:

```bash
gcc relogio_digital.c -o relogio_digital
